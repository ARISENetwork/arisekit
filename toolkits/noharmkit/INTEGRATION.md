# Local NOHARMKit

The viewer reads project data from disk. See [local setup](docs/agent-skills.md#manual-setup) and the [pipeline runbook](docs/runbook-e2e-mvp.md).

Imported validators, editors, and scoring code retain their source pins. Existing projects keep their recorded formats and scoring behavior. The [implementation reference](INTEGRATION_REFERENCE.md) links the manifests and their verification commands.
