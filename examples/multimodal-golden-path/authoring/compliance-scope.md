# Compliance scope

_Status:_ accepted

## Data classification

The PNG is an AI-generated synthetic radiograph-style phantom. It contains no
patient identifiers or patient-derived pixels. The source and image have a
public release posture.

## Boundaries

The fixture does not perform de-identification and does not authorize use of
real clinical images. A non-stub model run can send attached images to the
reviewed model provider named by the selected route.
