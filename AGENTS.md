# Local ARISEKit

For benchmark authoring, start with [the kit guide](docs/kits.md) and the [authoring skills](skills/README.md). Read the selected skill and carry its named artifact into the next stage. Keep clinical decisions with the benchmark author and label model-generated references and scores accurately.

For changes to the local toolkit, use the [contributor checks](CONTRIBUTING.md). Preserve existing project data, scorer versions, source provenance, and inference checkpoints. Run offline examples with synthetic fixtures. Obtain authorization before sending case data to a provider.
